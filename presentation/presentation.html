AI Ticket Management
System

Sistema agentico per l'analisi automatica di ticket complessi, decomposizione in sottorichieste strutturate e validazione human-in-the-loop.

🚨 Il Problema

Ticket complessi,
effort elevato

📄
Contenuto non strutturato Ticket con testo libero e allegati PDF multi-pagina difficili da interpretare
🔀
Sottorichieste nascoste Multiple richieste distinte all'interno di un unico ticket — difficili da identificare e separare
⏱️
Processamento manuale Elevato effort operativo e alto rischio di errori nella gestione
👉 Serve un sistema che automatizzi analisi, decomposizione e validazione
💡 La Soluzione

Un sistema agentico AI
end-to-end

🔍
Analisi
Lettura automatica di ticket e allegati PDF
🧩
Decomposizione
Identificazione e separazione di ogni sottorichiesta
✅
Validazione
Human-in-the-loop con editing in tempo reale
→ Output strutturato pronto per l'integrazione con sistemi enterprise (CSV / DB)
⚙️ Come Funziona

La Pipeline Agentica

📩 Input Ticket + PDF

Ricezione del ticket testuale e dell'allegato PDF multi-pagina

📄 Page Analysis Agent Parallel

Analisi pagina per pagina in parallelo → estrazione header, entità, summary

🔍 Subrequest Detection Agent Aggregation

Aggregazione delle informazioni → identificazione delle N sottorichieste distinte

✅ Validation Agent HITL

Validazione con operatore → editing live dei dati (es. codice fiscale)

💾 Persistence Output

Salvataggio strutturato su CSV / DB → pronto per sistemi enterprise

🤖 Agent Architecture

Quattro agenti,
un orchestratore

🧠

Orchestrator Agent

Coordina l'intero workflow — gestisce stato, sequenza e comunicazione tra agenti specializzati

📄

Extraction Agent

Sintesi e strutturazione del contenuto per ciascuna pagina del PDF

🔍

Detection Agent

Identifica e separa le sottorichieste distinte aggregando le estrazioni

✅

Validation Agent — Human-in-the-Loop

Presenta i dati all'operatore, raccoglie correzioni in tempo reale e persiste l'output validato
